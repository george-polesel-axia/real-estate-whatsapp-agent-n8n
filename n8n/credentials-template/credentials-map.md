# Mapa de Credenciais n8n

Crie credenciais no n8n com estes nomes sugeridos:

- `OpenAI Real Estate Agent`: API key para chat, embeddings e transcricao.
- `Supabase Real Estate REST`: URL Supabase e key de menor privilegio possivel.
- `WhatsApp Provider`: token/API key do provedor escolhido.
- `Google Calendar Brokers`: OAuth Google Calendar.
- `SMTP Real Estate`: envio de e-mail.

Nao cole secrets em nodes exportados. Use credenciais do n8n ou variaveis de ambiente.
